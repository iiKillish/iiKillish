#### Keyboard-driven KDE apps

A family of small Qt 6 / KDE Frameworks apps with no toolbars, done with keys, sharing one
zoxide-ranked jump popup.

- **Dolphoxide**: Dolphin, KDE's file manager, with Ctrl+J to jump to any folder
- **Vellum**: a PDF viewer that shows just the pages, with vim-style keys
- **Vitrine**: an image viewer that shows just the image
- **libjump**: the shared popup, as a small Qt library with a stable ABI
